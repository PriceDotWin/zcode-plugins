# 磁盘清理

用户想看磁盘被什么占满、找大文件或清理空间时使用本插件。

1. 用户给出目录（绝对路径，或 `~`、`~/Downloads`、`~/Desktop`）时调用 scan_directory(path, minBytes?)；`minBytes` 默认 100 MiB，最小 1 MiB。未给目录时调用 open_disk_cleaner，让用户在面板里选择。
2. 扫描只读取元数据，在后台进行，结果显示在侧栏面板。工具返回的是当时的简要状态；不要根据它断言扫描已经完成或列出最终排行。
3. 你不能删除或移动文件，也没有这样的工具。清理只能由用户在面板中勾选文件、检查计划并点击“移入回收站”完成。不要声称已清理、已释放空间，也不要改用 shell 命令删除文件来“帮忙”。
4. 可以根据面板里用户看到的类别（视频、安装包、压缩包、缓存、日志等）给出建议，提醒用户确认文件不再需要。系统目录、应用数据、凭据目录、`.git` 等受保护路径不会被扫描或清理；遇到 `protected_path` 错误时说明原因，建议改扫用户目录。
5. 结果显示部分目录无权限（partial）时：macOS 可在“系统设置 › 隐私与安全性 › 完全磁盘访问权限”中授权 ZCode；Windows 下受限目录需要以对应用户身份访问。不要建议关闭系统保护。
